# Vancraft
[Vancraft](https://vancraft.app) is a simple campervan interior layout planner that lets you design and visualize your van's interior in 2D and 3D.

Arrange furniture, kitchen units, beds, storage and other elements, customize their dimensions and positions and plan your space down to the millimeter.

Features include:
- Interactive top, side and rear views, plus a 3D preview
- Add, move, resize, duplicate and remove elements
- Automatic saving in your browser
- Export and import projects as JSON
